Two Sum

Given an integer array nums and an integer target, return the indices of two numbers whose sum is the target. Exactly one valid pair exists. Do not use the same element twice. Return either index order.

Language: TypeScript

function twoSum(nums: number[], target: number): [number, number]

Examples

nums = [2, 7, 11, 15], target = 9  → [0, 1]
nums = [3, 2, 4], target = 6      → [1, 2]
nums = [3, 3], target = 6         → [0, 1]

Explain the approach, implement the function, and give time and space complexity. Discuss duplicates and negative values.
